# Sumi 1.4.0 - App Store "What's New"

Paste-ready copy for the App Store / Play listing. Plain language, no markdown
needed in the store field. Copy rule: no middle dot, no em dash.

Scope: maintenance release. Cut as `prod/1.4.0`, RC tag `v1.4.0-RC1`.
There are no user-facing changes. The only substantive change is the Google
Play Billing Library upgrade to 9.0.0, required because Google rejects updates
built on Billing below 8.0.0 from 31 Aug 2026. Everything else is a puzzle
generator refactor, CI, and docs.

Same copy works for both stores. On iOS this build carries nothing at all, so
if App Store Connect will accept it, reuse the 1.3 text instead of shipping a
"nothing changed" note.

Maintenance and stability updates.
